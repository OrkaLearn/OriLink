# AGENTS.md

This file provides comprehensive guidelines for agentic coding agents operating in this secure social networking repository. It emphasizes security, code quality, and maintainability.

## SVG CAPTCHA Integration Policy (Login & Security)

**All login and signup forms MUST integrate and require successful SVG CAPTCHA verification from users.**

- The `/api/captcha` GET endpoint generates SVG CAPTCHAs using `svg-captcha` and stores answers in an in-memory token store (`server/captcha-store.js`) with 5-minute TTL
- The `/api/login` and `/api/register` backend routes MUST validate CAPTCHA by calling `captchaStore.verify(token, input)` before processing authentication
- CAPTCHA tokens are single-use (deleted after verification) and expire after 5 minutes
- The login/signup UI must display the SVG CAPTCHA with a refresh button and input field
- Any future modifications to login/auth/signup routes MUST NOT bypass CAPTCHA verification; attempts must be rejected server-side
- Frontend and backend testing must include CAPTCHA generation, verification, and error UX for failed/missing CAPTCHA attempts
- Any agent proposing to modify authentication must reference this policy and demonstrate continued CAPTCHA enforcement (both in UI and server functions)

## Bilingual UI Text Policy (English + Chinese)

**All user-facing text MUST be bilingual with English followed by Chinese.(Doesn't neccessarily have to be in same element)**

- **Format**: `"English Text" + " " + "中文文本"` (e.g., `Username 用户名`, `Loading... 加载中...`, `Login 登录`)
- **Applies to**: 
  - HTML labels, buttons, placeholders, titles, descriptions
  - JavaScript alert/error/success messages
  - Form validation messages
  - Navigation items and menu text
  - Admin panel UI text
  - Dynamic content generated by JavaScript
- **Order**: English comes FIRST, then a space, then Chinese
- **Examples**:
  - `Username 用户名` (label)
  - `Enter username 请输入用户名` (placeholder)
  - `Login 登录` (button)
  - `Loading... 加载中...` (status message)
  - `Error loading invitations 加载邀请出错` (error message)
- Any agent modifying or adding UI text MUST follow this bilingual format

## 2. Deployment & Nginx

OriLink runs on **esshasrv003** under the `kevin` user. Nginx reverse-proxies public traffic to the Node.js backend.

### Runtime

| Item | Value |
|------|-------|
| App directory | `/home/kevin/projects/orilink` |
| Backend port | `3210` (`server/index.js`) |
| Public domain | `ori.nekko.cn` |
| Nginx listen | `80`, `1234` |

### Nginx config (kevin-managed)

Config lives in the user home directory and is symlinked into nginx, same pattern as simon:

```
/home/kevin/nginx/kevin.conf
  ↑ symlink
/etc/nginx/sites-available/orilink
  ↑ symlink
/etc/nginx/sites-enabled/orilink
```

After editing `/home/kevin/nginx/kevin.conf`, reload nginx:

```bash
sudo nginx -t && sudo systemctl reload nginx
```

The `kevin` user has passwordless sudo for only these two commands (see `/etc/sudoers.d/nginx-kevin`).

The config proxies all paths (including `/api` and `/socket.io` WebSocket upgrades) to `http://127.0.0.1:3210/`.

### Systemd service

OriLink runs as **`kevin-orilink.service`** (user `kevin`, port `3210`).

```bash
# Preferred: use the web CLI (root shell)
web start kevin-orilink
web restart orilink
web status kevin-orilink
web logs orilink

# Or systemctl directly
sudo systemctl start kevin-orilink
sudo systemctl restart kevin-orilink
sudo systemctl status kevin-orilink
journalctl -u kevin-orilink -f
```

Service unit: `/etc/systemd/system/kevin-orilink.service`

After editing nginx config, reload with:

```bash
sudo nginx -t && sudo systemctl reload nginx
```

### Manual start (development)

```bash
cd /home/kevin/projects/orilink/server
node index.js
# or with nodemon for development
npx nodemon index.js
```

### Verify

```bash
curl --noproxy '*' -H 'Host: ori.nekko.cn' http://127.0.0.1:80/
curl --noproxy '*' -H 'Host: ori.nekko.cn' http://127.0.0.1:1234/
```

Use `--noproxy '*'` on this host if `http_proxy` is set (e.g. Clash on `127.0.0.1:7890`), otherwise curl may not hit local nginx.
